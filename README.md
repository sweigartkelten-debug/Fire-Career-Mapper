# 🚒 Fire Career Mapper

Fire Career Mapper (FCM) is an open-source Google Sheets and Google Apps Script application designed to help firefighters track their entire career.

## Version

**0.1.0 - Foundation**

## Project Goals

- Track every fire, EMS, rescue, hazmat, and special incident.
- Import CAD reports from multiple systems.
- Generate career statistics.
- Display incidents on Google Earth.
- Support configurable work schedules.
- Support multiple departments.
- Modular extension framework.
- Automatic updates and backups.
